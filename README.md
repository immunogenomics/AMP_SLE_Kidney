# AMP_SLE_Kidney
This repo provides code for the analysis of AMP SLE Phase 2 data from [Sugiarto, Gurajala, Curtis, Eisenhaure, et al, Science Translational Medicine, 2026](https://doi.org/10.1101/2025.08.11.669754).

The data is publicly available at [https://doi.org/10.7303/syn71763726.1](https://doi.org/10.7303/syn71763726.1) and is also available on the ARK portal at [https://arkportal.synapse.org/Explore/Datasets/DetailsPage?id=71763726](https://arkportal.synapse.org/Explore/Datasets/DetailsPage?id=71763726)
